## Stage2 changes

- add task-to-user package-state membership with per-user rwlock protection;
- bind after copy_creds succeeds;
- unbind on fork cleanup and normal release before user credentials can disappear;
- rebind on commit_creds while both old and new user references are still valid;
- add a Lisa split-WALT account_pkg_busy_time matching donor no-wait semantics;
- call update_pkg_load at the semantic WALT landing point using p->wts.mark_start and Lisa scale_exec_time;
- call package_runtime_monitor from do_timer;
- provide weak pkg_enable=false/update_pkg_load no-op defaults until real pkg_core arrives.

Stage2 therefore changes no device performance behavior by itself and cannot be called a jank fix. Its purpose is to prove the exact lifecycle/hook plumbing compiles before porting the larger pkg_core/migt_sched/glk/migt implementation.
