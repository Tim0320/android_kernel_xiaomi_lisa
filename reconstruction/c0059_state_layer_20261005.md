# Candidate0059 Stage1 package-runtime state layer

This stage is deliberately smaller than the final Android16 performance repair.

It introduces only the ABI-safe storage/lifetime layer required before stock-era Xiaomi package-runtime and MIGT accounting can be mapped into Lisa's split-WALT scheduler.

## Scope

Stage1 will:
- declare CONFIG_PACKAGE_RUNTIME_INFO under MIHW;
- replace task_struct KABI reserve 8 with one package-runtime pointer by ANDROID_KABI_USE;
- replace user_struct KABI reserve 2 with one package-runtime pointer by ANDROID_KABI_USE;
- keep the full package_runtime_info object outside the frozen structures;
- allocate a fresh task state after the existing fork cleanup-safety initialization and free it from free_task;
- allocate/free per-user state through alloc_uid/free_user, with static backing for root_user;
- add only kernel/sched/pkg_state.o.

Stage1 explicitly does not expose /dev/migt or /dev/metis, port MIGT ioctls, add WALT boost/accounting hooks, alter cpuset affinity, create /dev/iorap_dev, fake an ioctl, or start the full Candidate0059 build.

## Failure-path rule

dup_task_struct copies the parent's KABI pointer. The Stage1 prepare helper first clears that borrowed pointer before allocating child state. The call is inserted only after set_child_tid/clear_child_tid, ftrace graph initialization, and rt_mutex task initialization, so an allocation failure can safely use the existing bad_fork_free path.

## Validation

The dedicated Stage1 Action applies the mutator to the exact pinned Lisa source, enables MIHW + PACKAGE_RUNTIME_INFO on the stock configuration, runs olddefconfig/prepare, and compiles the affected state/lifetime objects only.

A Stage1 compile PASS proves only that the KABI-safe state plumbing builds. It does not prove the full MIGT/package-runtime port, Android16 jank improvement, or device runtime behavior.
